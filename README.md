# Z.ai — синхронизация ZCode между компьютерами

Единый источник скиллов и глобальной памяти ZCode. Один набор на всех машинах.

## Что синхронизируется

| Что | Куда устанавливается | Как синхронизируется |
|---|---|---|
| Скиллы (`skills/`) | `~/.zcode/skills/`, `~/.agents/skills/` | этот репозиторий |
| Глобальная память (`AGENTS.md`) | `~/.zcode/AGENTS.md` | этот репозиторий |
| Память по проектам | `<проект>/AGENTS.md` | git-репозиторий самого проекта |

Память по конкретному проекту лежит внутри проекта (`<проект>/AGENTS.md`) и
уезжает вместе с ним через git самого проекта — здесь для неё ничего делать не нужно.

## Новая машина

```bash
git clone https://github.com/Taner-Engineer/Z.ai.git
cd Z.ai
./install.sh        # Git Bash / Linux / macOS
# или в PowerShell:  .\install.ps1
```

После установки перезапустите ZCode, чтобы скиллы подхватились.

## Обновиться на этой машине

```bash
./update.sh         # Git Bash / Linux / macOS
# или в PowerShell:  .\update.ps1
```

## Изменить скилл / глобальную память

1. Отредактируйте файл в этом репозитории (например `AGENTS.md` или `skills/<имя>/SKILL.md`).
2. Запустите `install`-скрипт, чтобы изменения применились локально.
3. Сделайте commit и push.

```bash
./install.sh
git add -A && git commit -m "обновил скиллы" && git push
```

На других машинах затем запускается `./update.sh`.

## Добавить новый скилл

Положите папку скилла (с `SKILL.md` внутри) в `skills/`, запустите `install`,
закоммитьте и запушьте. Скрипты не трогают скиллы, которых нет в репозитории, —
локальные эксперименты не пропадут.

## Установка официальных плагинов

Плагины (document-skills, browser-use и др.) ставятся из маркетплейса ZCode и
здесь не хранятся. На новой машине доустановите их через Settings → Plugin Management.
