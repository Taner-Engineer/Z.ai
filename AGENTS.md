# Глобальная память ZCode

Эти правила применяются во всех проектах на любой машине. Файл синхронизируется
через репозиторий Z.ai — отредактировали здесь, сделали commit + push, на другой
машине запустили `update.sh` / `update.ps1`.

## Язык и общение

- Отвечай по-русски.
- Отвечай кратко и по делу, без воды.

## Предпочтения по коду

- Комментируй код только там, где без комментария не понять.
- Не добавляй зависимости без необходимости.

## Окружение

- ОС: Windows, терминал: Git Bash.

## Самопроверка и самовосстановление

- После запуска долгих задач (конвейеры, волны обработки, очереди, фоновые
  процессы) — проверять их живость и результат по логам/состоянию самому,
  не дожидаясь фидбека пользователя.
- Процесс умер, задание упало или результат не долез — перезапускать и чинить
  самому, переиспользуя уже сделанное (кеш/чекпойнты/resume). Не спрашивать
  «перезапустить?» — перезапускать и отчитываться фактом.
- Ко мне — только решения, которые реально меняют деньги, данные или
  направление работы; рутина восстановления — на агенте.

## Железо и параллелизм

- Продумывая архитектуру любого конвейера/обработки, сначала учитывай железо
  целевой машины: рабочий ПК — i7-14700KF (8P+12E, 28 потоков), 32 ГБ RAM,
  RTX 3050 6 ГБ; homelab — только оркестрация, его CPU под тяжёлое не тратить.
- По умолчанию закладывай параллелизм: CPU-bound — пул процессов на ~половину–2/3
  логических ядер, GPU-bound — батчи/шардирование; однопоточный обход больших
  наборов файлов не писать.
- Для pymupdf/docling/numpy — процессы, а не потоки (GIL и потокобезопасность);
  на Windows не забывать `if __name__ == "__main__":`.

## Хранилище знаний 2brain

- Общая база: `C:\Users\Us\Vaults\2brain` — книги, нормативы, видео, статьи; проектные материалы в `Projects/<имя>/`. Полные тексты: `Books/`, `Normatives/`, `Knowledge/`, `Projects/<имя>/`.
- Поиск по базе всегда так, без перечитывания текстов целиком: реестр `_llm/Index.md` → заметка-Карта в `_llm/notes/` → точечное чтение полного текста.
- `_llm/Index.md` генерируется `_llm/gen_index.py` — руками не редактировать, других индексов не создавать.
- Перед любыми изменениями в ваулте прочитай доктрину: `CLAUDE.md` в его корне.
